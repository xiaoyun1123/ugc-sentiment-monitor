# UGC 情感监控分析平台

多平台 UGC 内容的自动化采集、AI 情感分析与可视化监控仪表盘。

## 功能
- **数据采集**：小红书、B站、知乎三平台，支持关键词搜索与热榜追踪
- **AI 情感分析**：调用 DeepSeek 大模型自动标注情感倾向
- **可视化看板**：Streamlit 交互界面，展示情感占比、日度趋势、高频词云、头部内容排行
- **动态筛选**：按平台、日期范围筛选，支持原始数据导出
- **性能**：单次任务 30 秒内完成多平台数据抓取与 AI 分析

## 技术栈
Python · DeepSeek AI · Streamlit · Pandas · 数据采集
